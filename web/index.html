Setup

  1. In Nextcloud, open Settings → Personal → Security → Devices & sessions.
  2. Enter a device name (e.g. nextcloudmcp) and click Create new app password.
  3. Copy the generated app password and paste it below with the Nextcloud URL and your username.
  4. Click Test connection, then Save.
  5. Auto-respond is on by default — Claude will reply to your DMs and @mentions as soon as an LLM target is discovered. Toggle it off below if you don't want that.
